File: NCA All MetaAnalysis Data.csv – This file contains all of the data and associated metadata used within the manuscript titled Prevalence of Predator Risk Effects in Coastal Wetlands, submitted to Ecosphere. The content below includes all of the relevant information for each column in the dataset.

Unique:	Unique identifying number associated with each treatment comparisons extracted from the cited studies.
ID:	Unique identifying number for each study from which data were extracted.
Author:	Main authors for each study.
Year:	Publishing year of each study.
Study Type:	Designation of the type of research study (e.g., observational, experimental, etc.)
Region:	Geographic region in which the study took place.
Habitat:	Habitat type in which the study took place.
Predator Type:	Predator type under study.
Prey Type:	Prey type under study.
Basal Resource:	Basal resource under study.
System:	Simple description of the trophic connections within the study.
Response Type:	Response variable type, categorized as Risk-Induced Trait Response (RITR), Trait-Mediated Indirect Effect (TMIE), or Non-Consumptive Effect (NCE).
Response Variable:	Measured response variable
Response Metric:	Metric used to measure the response variable
Control Mean:	Self-explanatory
Control Sample: Size	Self-explanatory
Control CI.95:	95% confidence interval for the control mean (if applicable)
Control CI.85:	85% confidence interval for the control mean (if applicable)
Control t Distribution Value:	Self-explanatory
Control StdErr:	Self-explanatory
Control StdDev:	Self-explanatory
Treatment Mean:	Self-explanatory
Treatment Sample Size:	Self-explanatory
Treatment CI.95:	95% confidence interval for the treatment mean (if applicable)
Treatment CI.85:	95% confidence interval for the treatment mean (if applicable)
Treatment t Distribution Value:	Self-explanatory
Treatment StdErr:	Self-explanatory
Treatment StdDev:	Self-explanatory
Effect Size:	Calculated effect size comparing the control outcomes to the treatment outcomes
Relative Difference:	Relative difference between the control outcome and the treatment outcome
Notes:	Notes indicated specific details on how data were collected from the study.
